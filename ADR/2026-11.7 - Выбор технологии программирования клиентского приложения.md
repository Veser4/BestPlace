
**Дата:** 7 ноября 2026 г.

**Статус:** Принято

**Контекст:** 

Проект является исключительно веб-приложением с приоритетом мобильных устройств (mobile-first). Требуется высокоинтерактивный интерфейс (карта, списки, динамические фильтры) со временем отклика не более 3 секунд

**Рассмотренные варианты:**

1. **React:** Популярная и быстро развивающаяся библиотека для создания пользовательских интерфейсов
2. **Vue.js:** Прогрессивный фреймворк с легким входом и гибкостью
3. **TS / HTML / CSS:** Быстро работает, но сложно поддерживать при росте проекта.


**Решение:**

Выбран React + TypeScript

**Обоснование:**

- **Мощное сообщество:** Огромное сообщество разработчиков и множество доступных ресурсов обучения и поддержки.
- **Компонентный подход:** Позволяет создавать переиспользуемые компоненты, что ускоряет процесс разработки и обеспечивает стабильность приложения.
- **Гибкость:** React предоставляет гибкость в выборе инструментов и архитектурных решений.
- **Производительность:** Виртуальный DOM обеспечивает быструю перерисовку интерфейса.
- **Совместимость:** React может интегрироваться с различными бэкенд-технологиями и API.
- **Стек технологий:** React и TypeScript явно разрешены ограничениями проекта
- **Надежность:** Использование TypeScript снизит количество багов в рантайме благодаря строгой типизации в любом размере проекта

**Последствия:**

- Все клиентские приложения будут разработаны с использованием React + TS.
- Необходимо провести обучение или усилить текущие знания команды в области React и связанных с ним инструментов.
- Следует активно использовать экосистему React (например, Redux, React Router, Reatom) для оптимизации разработки и обеспечения лучшего пользовательского опыта.
- Приложение будет реализовано как Single Page Application.
- Необходима настройка сборщика (Vite/Webpack) и строгого линтера
