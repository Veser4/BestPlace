**Дата:** 7 ноября 2026 г.

**Статус:** Принято

**Контекст:**

Приложение должно визуализировать маркеры на карте, переключаться между списком и картой, а также позволять пользователю строить маршруты во внешнем навигаторе. Разработка ведется без бюджета

Рассмотренные варианты:

1. Google Maps API: Высокая точность в мире, но платная тарификация после исчерпания лимитов. В РФ работает с ограничениями
2. Yandex Maps API: Отличная детализация по России. Есть бесплатный тариф для открытых некоммерческих проектов
3. OpenStreetMap + Leaflet: Полностью бесплатно, но менее привычный UI для пользователя и слабее детализация мелких тропинок в СНГ

**Решение:**

Выбран Yandex Maps API

**Обоснование:**

- **Маршрутизация:** Мы не строим маршруты внутри приложения. По клику на кнопку мы передаем координаты через URL-схемы в установленные на телефоне навигаторы. Это снимает с нас затраты на платное API маршрутизации
- **Бюджет:** Yandex Maps API предлагает бесплатный тариф для публичных сервисов
- **Доступность:** При недоступности сервиса карт само приложение продолжит работать в режиме "Списка"

**Последствия:**

- Реализовать генерацию ссылок для внешних переходов, те переход 
- Привязка к вендору. Если проект будет монетизироваться, придется платить
- На фронтенде использовать обертки для Яндекс.Карт
