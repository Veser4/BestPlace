
**Дата:** 7 ноября 2026 г.

**Статус:** Принято

**Контекст:**

Нам нужна надежная и масштабируемая база данных для нашего проекта BestPlace. Выбор базы данных может влиять на производительность, масштабируемость и безопасность нашего решения.

**Рассмотренные варианты:**

1. **PostgreSQL:** Объектно-реляционная система управления базами данных.
2. **MySQL:** Классическая реляционная БД. Поддерживает Spatial-расширения, что надо для анализа, хранения географических и пространственных данных
3. **MongoDB:** Документоориентированная система управления базами данных.

**Решение:**

Выбран MySQL

**Обоснование:**

- **Надежность:** известен своей стабильностью и надежностью, даже при работе с большими объемами данных.
- **Расширяемость:** поддерживает расширения, что позволяет добавлять новые возможности по мере необходимости.
- **Сообщество:** Большое и активное сообщество, множество доступных материалов и ресурсов для обучения.
- **Соблюдение ограничений:** MySQL строго прописана в разрешенном стеке технологий
- **Гео-запросы:** Современные версии MySQL имеют встроенные пространственные типы данных и функции, что полностью покрывает потребность в сортировке локаций по удаленности
- **Реляционность:** Структура данных (пользователи, роли, карточки мест, категории, статусы) сильно связана, реляционная модель здесь идеальна.
  
**Последствия:**

- Все данные проекта будут храниться в MySQL.
- Необходимо убедиться в компетентности команды в работе с MySql или предоставить соответствующее обучение.
- Координаты будут храниться в формате с использованием Spatial.
