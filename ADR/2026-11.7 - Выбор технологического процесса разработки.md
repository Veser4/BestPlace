
**Дата:** 7 ноября 2026 г.

**Статус:** Принято

**Контекст:**

Для сервиса BestPlace необходимо выбрать инструменты автоматизированного тестирования. Нам нужно гарантировать надежность ключевых сценариев и контроль требований по скорости отклика

**Рассмотренные варианты:**

1. **Ручное тестирование:** Проверка функционала разработчиками вручную без написания тестов
2. BDD-стек - Gherkin: Тестирование сценариев на естественном языке с распределенной инфраструктурой
3. Go testing + testify / Vitest + RTL / Playwright: Использование встроенных и бесплатных инструментов экосистем Go и TypeScript  

**Решение:**

Выбран Go testing + testify / Vitest + RTL / Playwright

**Обоснование:**

- **Нулевая стоимость:** Все инструменты распространяются по открытым бесплатным источникам
- **Соответствие стеку:** Тесты пишутся на Go и TypeScript, не требуя освоения сторонних языков или сложных DSL
- **Изоляция проверок:** testify позволяют быстро протестировать валидацию файлов и правила доступа без развертывания боевой БД   
  
**Последствия:**

- Юнит-тесты станут обязательным условием прохождения CR
- E2E-тесты будут покрывать только критические сквозные сценарии пользователя и модератора
- Скриншотные тесты покрывают основные компоненты дс проекта
